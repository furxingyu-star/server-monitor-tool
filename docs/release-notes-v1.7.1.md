# 星语哨兵 v1.7.1

## 变化

- **修复设置页交互卡顿（本次主线）**：在设置页滚动后（或刚滚动完立刻点控件）会冻结 130–190ms，表现为「不太丝滑」。
  - 根因：壁纸自适应着色 `tintCards()` 对每张可见卡片把整张 4K 壁纸的子矩形 `drawImage` 到 8×8 canvas 再 `getImageData` 读回 —— 每次都在主线程做一次同步 GPU 读回（实测每张 14–91ms，设置页 3 张可见卡 ≈150ms，概览页卡片更多更糟）。滚动停止 140ms 后的定时器必然触发它。
  - 修法：壁纸加载时把壁纸一次性缩到 192px 宽的采样网格（`buildWallGrid`），之后 `tintCards()` 纯 JS 在网格上按卡片矩形取最多 8×8 点求均值，热路径不再创建 canvas、不再 `getImageData`；`--adapt` 计算公式与视觉结果不变。
  - 附带：`sampleWallSeed` 按壁纸路径缓存，避免每次应用像素调色板都做一次 16×16 读回。
- **设置页「外观模式」恢复单行**：像素主题下 `.seg-row` 的网格轨道下限 120px 会把 279px 窄列里的三个按钮挤成两行（行高 98px），改为 `minmax(0, 1fr)` 后是一行三等分（按钮 86×33）。
- **终端最后一行被裁（显示不全）**：终端视图里 xterm 内容比卡片高 11px，底部最后一行（SSH banner 的 `Last login` / 提示符）被卡片 `overflow:hidden` 裁掉一半。
  - 根因：xterm 的 FitAddon 只减 `.xterm` 自身内边距，而它量的是父容器 `.term-body` 的 border-box 高度（583px），没减 `.term-body` 自己的 `14px/10px` 上下内边距 —— 于是按 583px 算出 33 行（580px），实际内容区只有 559px，溢出 11px 被裁。
  - 修法：`.term-body` 内加一层无内边距、高度 100% 的 `.term-host` 承载 xterm，FitAddon 量到的就是真实内容区（559px → 30 行）；再加 `ResizeObserver` 跟随主题/外观切换后 `.term-body` 内边距变化重新 fit。
- **悬浮窗与主面板统一为同一套 Material You 表面**（此前两窗一个是实色卡片、一个是半透明壁纸+蓝色光斑，观感割裂）：
  - 悬浮窗删除像素主题下的壁纸与 `.veil` 光斑（主面板像素主题本就是干净实色），窗口底色改用**卡片色** `--p-surface-1`（深色实测 rgb(24,26,29)，与主面板卡片逐像素一致），圆角 28 → 24，mini 18。
  - 调色板改用与主面板 `applyPixelPalette()` 完全相同的 M3 角色公式（此前悬浮窗的 on-surface/variant/muted 饱和度是另一套数值，两窗同屏时颜色不是同一个色）。
  - 网络条、底部信息条改为 `--p-surface-2` / 透明；图标按钮改透明底 + `on-surface-variant`（对齐主面板 40px 透明圆钮）；环形轨道用 `--p-surface-3`，CPU 环取主色；状态点在演示模式显示琥珀色（此前恒绿）。
  - 字体统一为 Pixel Sans（此前只有品牌/时间用，其余回退 Segoe UI）。

- **启动第二个副本时会多出第二个面板**：`requestSingleInstanceLock()` 只在同一个 `userData` 目录内互斥 —— 从两份解压目录启动，或带不同 `--user-data-dir` 启动（旧版本残留、调试实例），就会并排出现两个窗口。
  - 修法：再加一层本机回环端口锁（46321–46323）。先占端口的是主实例；后来者握手确认身份后，先请主实例回到前台（最小化/收进托盘也会被叫回来），自己安静退出。实测第二个副本 236ms 退出、退出码 0、前台落回已有主面板。
  - 三个端口都被别的程序占用时退化为只管本 `userData`，不会挡启动；调试时可用 `--allow-multi` 或 `SENTINEL_ALLOW_MULTI=1` 显式跳过。

## 实测（1240×820，像素主题，CDP 采样 900ms 窗口）

| 场景 | v1.7.0 | v1.7.1 |
| --- | --- | --- |
| 设置页滚动 | 最长帧 133–150ms，有 >33ms 掉帧 | 16.8ms，0 掉帧、0 longtask |
| 滚动后点「外观模式」浅色/深色 | 100–167ms | 16.8ms |
| 滚动后展开语言 / 切换猫猫语 | 133–167ms | 16.8ms |
| 滚动后切强调色、悬浮窗尺寸 | 83–167ms | 16.8ms |
| 连续快速切换 7 个控件 | 多次卡顿 | 最长 33.3ms、0 longtask |
| 导航切页（概览→性能→容器→网站→设置） | 正常 | 16.8–16.9ms |

壁纸采样网格一次性构建成本 0.3–0.4ms（7676×4316 壁纸）。

## 已知成本（未改动）

- 像素 → 玻璃玻玻璃主题切换仍有约 170–220ms 首帧停顿：来自 27 个毛玻璃面板同时启用 `backdrop-filter`（含 SVG 位移透镜）时的重新栅格化，属渲染管线成本，砍掉它会牺牲玻璃质感与色散效果。像素主题下无此问题。

## 安装

1. 下载 `star-sentinel-v1.7.1-win32-x64.zip`，**整包解压**（不要只把 StarSentinel.exe 拿出来，会缺 ICU 数据）。
2. 运行 `StarSentinel.exe`。首次启动是演示模式，到「设置」填宝塔 API 或 SSH 即可接入自己的服务器。
3. 系统要求：Windows 10 / 11 x64，免安装、免 Node。
