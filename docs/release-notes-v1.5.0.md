# 星语哨兵 v1.5.0

## 变化

- **只保留像素（Pixel · Material You）主题**：移除深空 / 紫霭 / 深海 / 熔金 / 石墨 / 晨雾六套旧主题，设置页「主题与外观」只剩一张主题卡；主题卡、强调色、外观模式改为三列并排。
- **删除「外观选项」**：移除液态玻璃折射、流畅模式两个开关，以及「玻璃质感」清透 / 均衡 / 冰霜三档；`renderer/glass.js`（SVG SDF 折射滤镜）一并删除。
- 默认外观改为像素主题 + Material You 蓝（#1a73e8）；旧配置里的 `liquid` / `lowFx` / `glass` 字段启动时被忽略，下次保存时从设置中清掉。
- **移除壁纸管理页**：导航与托盘去掉「壁纸」入口，删除内置预设、图库扫描、显示方式与「应用到桌面」能力（wallpaper.js 只保留读取当前壁纸）。面板与悬浮窗仍以当前壁纸作底色，像素主题依旧从壁纸取色。
- **侧边导航动画**：选中项改成滑动的 Material You 指示胶囊（切换页面时在菜单项之间平滑过渡），菜单项悬停有图标缩放与文字轻移，启动时逐项淡入；尊重系统「减少动态效果」设置。
- 像素主题的深浅两套皮肤、壁纸动态取色、外观模式（跟随系统 / 浅色 / 深色）保持不变。

## 安装

1. 下载 `star-sentinel-v1.5.0-win32-x64.zip`，**整包解压**（不要只把 StarSentinel.exe 拿出来，会缺 ICU 数据）。
2. 运行 `StarSentinel.exe`。首次启动是演示模式，到「设置」填宝塔 API 或 SSH 即可接入自己的服务器。
3. 系统要求：Windows 10 / 11 x64，免安装、免 Node。
