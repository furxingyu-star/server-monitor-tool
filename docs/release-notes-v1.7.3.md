# 星语哨兵 v1.7.3

## 变化

- **猫猫语：所有文案统一补「喵」，并补齐核心术语**（本次主线）
  - 后缀规则：原来只在「以汉字收尾」时补「喵~」，别的结尾就漏了。现在：**以汉字收尾的文案一律补「喵」**；以冒号、逗号、括号、破折号收尾的提示语不补（避免「关闭主界面时：喵」）。
  - 以字母 / 数字收尾的不补，因为那是机器型号、版本号、容量、速率这类**数据**（「Intel Xeon Platinum 82」「11.7.0」「剩余 21.2 GB」），补上会长出「82喵」，反而把真实值糊掉。
  - 术语表：CPU → **脑瓜**，内存 → **小口袋**，磁盘 → **大仓库**，负载 → **压力**（悬浮窗的 LOAD 同样按「压力」），性能 → **跑酷速度**。于是显示为「脑瓜喵」「小口袋喵」「大仓库喵」「压力喵」「脑瓜 核心喵」「系统压力喵」「压力水位喵」「跑酷速度喵」。
  - 说明：你给的候选里「喵喵处理器 / 猫舍大仓库」在卡片标题（约 60–72px 宽）和分段控件按钮里会折行，所以先取同义的短名（脑瓜 / 大仓库）；想换回长说法可以再说，我把标题字号再压一档。
- **猫猫语下的折行修复**：卡片标题（含趋势文案如「2 个分区喵」）加 nowrap，长词不再被挤成两行；1240px 像素深色实测概览 / 性能 / 设置五个视图 + 悬浮窗逐元素扫描，**0 处非预期折行**。
- **实测**（dev 实例 1240×820，像素深色，猫猫语）：「脑瓜喵 39px / 小口袋喵 52px / 大仓库喵 52px / 2 个分区喵 54px」全部单行；性能页「系统压力」三列标签 42 / 42 / 49px 单行；导航「跑酷速度喵」单行。
- 其余与 v1.7.2 相同（猫猫语标签掉行、设置页滚动卡顿、终端最后一行被裁、悬浮窗统一材质、跨副本单实例保护）。

## 安装

1. 下载 `star-sentinel-v1.7.3-win32-x64.zip`，**整包解压**（不要只把 StarSentinel.exe 拿出来，会缺 ICU 数据）。
2. 运行 `StarSentinel.exe`。首次启动是演示模式，到「设置」填宝塔 API 或 SSH 即可接入自己的服务器。
3. 系统要求：Windows 10 / 11 x64，免安装、免 Node。
