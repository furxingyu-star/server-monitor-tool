# 星语哨兵 v1.7.2

## 变化

- **猫猫语下「系统负载」三列标签掉行**：性能页卡片在 1180px 以上是 4 列布局，卡片内容区只有 184px；「1 分钟 / 5 分钟 / 15 分钟」加喵后变成「1 分钟喵~」等，每列只剩 45px，末尾的「~」被挤到第二行，卡片高度从 200px 涨到 204px，标签看起来断成两截。
  - 修法：`.load-big i` 加 `white-space: nowrap`，标签不再断行；像素主题把三段间距 24px → 14px、标签字号 10.5px → 10px，实测 1181px（4 列最窄）到 1240px 都单行放得下，第三个标签仍在卡片内边距以内，不会越界或被裁。
  - 附带扫了全部视图的猫猫语断行（逐文本节点比对中/猫两套的行数）：只剩设置页「外观模式」的「跟随系统喵~」会被 86px 的按钮挤成两行，把「跟随系统 / 浅色 / 深色」加入 `cat-speak.js` 的 KEEP 名单（与「像素」「玻璃玻玻璃」同样处理），三个选项保持单行一致。
- 其余与 v1.7.1 相同（设置页滚动卡顿、终端最后一行被裁、悬浮窗统一材质、跨副本单实例保护）。

## 安装

1. 下载 `star-sentinel-v1.7.2-win32-x64.zip`，**整包解压**（不要只把 StarSentinel.exe 拿出来，会缺 ICU 数据）。
2. 运行 `StarSentinel.exe`。首次启动是演示模式，到「设置」填宝塔 API 或 SSH 即可接入自己的服务器。
3. 系统要求：Windows 10 / 11 x64，免安装、免 Node。
