# 星语哨兵 v1.6.0

## 变化

- **新增「玻璃玻玻璃」液态玻璃主题（v1.6 主线）**：参考 [Kyant0/AndroidLiquidGlass](https://github.com/Kyant0/AndroidLiquidGlass)，主面板六个页面（概览 / 性能 / 容器 / 网站 / 终端 / 设置）与悬浮窗全部换成深色液态玻璃。
  - 折射真做了：`renderer/glass.js` 按卡片圆角与尺寸生成 SDF 位移贴图，经 `feDisplacementMap` 做「边缘透镜 + 中心微凸」的折射，叠三通道色散，作为 `backdrop-filter` 的滤镜链作用在背后真实壁纸上；卡片内容浮在滤镜层之上，不被模糊。
  - 材质层：深色蓝紫玻璃底、顶部径向反光、1px 镜面倒角环（遮罩挖空）、外投影与内高光；导航胶囊、按钮、网络条、圆环轨道、悬浮窗同步玻璃化。
  - 壁纸压暗提饱和后透出，面板之间能感到「背后有光在流」。
- **玻璃主题可自选壁纸**：液态玻璃需要「有细节」的背景才看得出折射，所以玻璃玻玻璃可以单独换一张壁纸——设置 → 主题与外观 → 玻璃壁纸「选择图片」，选中即时生效（主面板 + 悬浮窗一起换），「跟随桌面」恢复用系统壁纸；像素主题始终跟随桌面壁纸并据此取色。壁纸只存本机路径，不上传。
- **两套主题并存**：设置页「主题与外观」主题列变成像素、玻璃玻玻璃两张卡，点卡片即时切换并记住；首屏用 localStorage 回填主题，启动不闪错皮肤。
- **玻璃玻玻璃固定深色**：该主题下「外观模式」三档自动禁用并提示「切回像素主题可选浅色 / 深色」；切回像素后浅色 / 深色照常可用。
- **性能**：折射滤镜只在玻璃玻玻璃主题按需挂载（`glass.js` 懒加载），像素主题下不注入 SVG 滤镜、零额外开销；并遵循系统「减少动态效果」。
- 像素（Pixel · Material You）主题、壁纸动态取色、侧边导航动画、v1.5 的主题 / 壁纸精简保持不变。
- **最小化改为收进任务栏**：标题栏最小化按钮不再默认把主面板收进托盘（旧行为在设置里叫「最小化按钮收进托盘」），现在正常最小化到任务栏，点任务栏或托盘图标都能恢复；设置页移除了这个开关，「关闭」按钮的托盘 / 退出行为不变。
- 版本号 1.6.0；新增 `renderer/glass-theme.css`，恢复 `renderer/glass.js`（改为按主题懒加载）。

## 安装

1. 下载 `star-sentinel-v1.6.0-win32-x64.zip`，**整包解压**（不要只把 StarSentinel.exe 拿出来，会缺 ICU 数据）。
2. 运行 `StarSentinel.exe`。首次启动是演示模式，到「设置」填宝塔 API 或 SSH 即可接入自己的服务器。
3. 系统要求：Windows 10 / 11 x64，免安装、免 Node。
