# 星语哨兵 v1.7.4

## 变化

- **修复「强调色每次重开都变回壁纸取色」（本次主线）**：像素主题调色板一直按壁纸主色生成，用户手选的强调色只在当次运行有效。
  - 原因：像素主题用「壁纸取色」还是「手选强调色」由一个内存变量 `pixelAccentSeed` 决定；它没有写进设置，且 `loadWallSample()` 在每次启动加载壁纸时都会把它重置为 `false`。于是重启后必然回到壁纸色。
  - 修法：新增 `ui.accentCustom` 并随设置持久化（点预设色 / 自定义取色板写 `true`，保存设置时一并保存）；启动时先恢复该标记再配色；`loadWallSample()` 不再清除它。
  - 兼容：老配置文件没有 `accentCustom` 时，若已保存的强调色不是默认蓝 `#1a73e8`，视为手选；默认配置仍保持「从壁纸取色」不变。
- **悬浮窗同步同一规则**：`renderer/widget.js` 的像素调色板也改为「手选强调色优先」，与主面板同一色号。
- 附带：截图模式（`--accent=`）也把该强调色标记为手选，截图不再被壁纸色覆盖。

## 实测（隔离 profile，CDP，pixel 主题）

| 场景 | 修复前 | 修复后 |
| --- | --- | --- |
| 选橙色 #ffc46b → 页面刷新（等价重启） | 主色变回壁纸蓝 | 主色 `#ce7f09` 保持一致 |
| 同上，深色外观 | — | 主色 `#eccea2`，卡片表面 `#1e1b18` |
| 悬浮窗 | 用壁纸色，与主面板不同色 | `#eccea2` / 卡片 `#1e1b18`，与主面板完全一致 |

设置里保存的 `ui.accent` / `ui.accentCustom` 在重启后读回为 `true`，控制台无报错。

## 安装

1. 下载 `star-sentinel-v1.7.4-win32-x64.zip`，**整包解压**（不要只把 StarSentinel.exe 拿出来，会缺 ICU 数据）。
2. 运行 `StarSentinel.exe`。首次启动是演示模式，到「设置」填宝塔 API 或 SSH 即可接入自己的服务器。
3. 系统要求：Windows 10 / 11 x64，免安装、免 Node。
