# 星语哨兵 v1.7.0

## 变化

- **新增语言：简体中文 / 中文猫猫语（v1.7 主线）**：设置 → 主题与外观 → 语言，默认折叠成一行（「语言 · 当前语言 · ▾」），点开是「简体中文 / 中文猫猫语 🐱」两枚分段按钮，选中即时生效。
  - 整套界面文案喵化：句尾「喵~」、名词替换（服务器→猫舍、终端→爪爪终端、用户名→铲屎官名、容器→小窝、网站→领地、性能→体力、数据源→猫粮来源、密码→爪印密码、密钥→小鱼干钥匙、吃饭→恰饭饭、睡觉→摊猫饼…），标题按页面加 🐾 / ⚡ / 📦 / 🌐 / ⚙️。
  - 实现是运行时的轻量文案层（`renderer/cat-speak.js` + MutationObserver）：只改界面文字，不动数据——IP、端口、密钥、路径、终端输出、`<pre>/<code>`、输入框里的配置值一律原样；动态插入的文字也会被翻译，切回简体中文可完整还原。
  - 托盘菜单同步喵化（打开猫舍面板喵~ / 立刻巡逻喵~ / 溜了溜了喵~），悬浮窗（主面板与 252×100 迷你）也跟着改。
  - 语言选择写入本地设置并记住，下次启动沿用；像素与玻璃玻玻璃两套主题、外观模式、壁纸取色都不受影响。
- 版本号 1.7.0；新增 `renderer/cat-speak.js`，设置页新增折叠式语言行。
- 其余（v1.6 的玻璃玻玻璃主题与自选壁纸、v1.5 的主题精简与移除壁纸管理页）保持不变。

## 安装

1. 下载 `star-sentinel-v1.7.0-win32-x64.zip`，**整包解压**（不要只把 StarSentinel.exe 拿出来，会缺 ICU 数据）。
2. 运行 `StarSentinel.exe`。首次启动是演示模式，到「设置」填宝塔 API 或 SSH 即可接入自己的服务器。
3. 系统要求：Windows 10 / 11 x64，免安装、免 Node。
