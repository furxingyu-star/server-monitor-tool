# 星语哨兵 v1.4.0

## 新增

- **像素主题（Pixel · Material You）**：第 7 套主题，实色 M3 表面、胶囊按钮、Material 阴影与动效；跟随壁纸取色，也可以点强调色圆点手动指定主色（换壁纸自动回到壁纸取色）。
- **外观模式**：跟随系统 / 浅色 / 深色，作用于像素与晨雾两套浅色系主题，悬浮窗同步。
- **服务器改名**：概览卡片上的铅笔按钮（或双击名字）就地改名，可在设置里改回自动命名（用宝塔域名 / SSH 主机名）。
- **小窗启动设置**：设置里可选悬浮窗是否随软件启动；关闭主界面可选「最小化到托盘 / 退出」，并可设置关闭提醒。

## 优化

- 去掉「胶囊 + 闪烁圆点」那套元素：连接状态胶囊、LIVE 胶囊、导航计数小点、状态圆点都改成朴素文字，主题卡缩略图重做。
- 刷新数据按钮改为深色主按钮，与「打开宝塔」拉开主次。
- 液态玻璃折射与流畅模式改为互斥：开流畅模式自动关折射并记住原设置，关掉后恢复；像素主题下玻璃控件自动禁用并给出说明。
- 修复切换视图时图表偶发模糊横带；修复晨雾主题深色下内容区发白。

## 安装

1. 下载 `star-sentinel-v1.4.0-win32-x64.zip`，**整包解压**（不要只把 StarSentinel.exe 拿出来，会缺 ICU 数据）。
2. 运行 `StarSentinel.exe`。首次启动是演示模式，到「设置」填宝塔 API 或 SSH 即可接入自己的服务器。
3. 系统要求：Windows 10 / 11 x64，免安装、免 Node。
